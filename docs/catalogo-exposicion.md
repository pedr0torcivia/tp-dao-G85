# Catálogo y casos de exposición

La carga para la defensa usa **20 obras reales y 60 ejemplares**: tres copias por título, dos de Biblioteca Central y una de Biblioteca Norte. Los códigos **EXPO-001 a EXPO-060** identifican copias, no obras. Las sedes, socios, inventarios y operaciones son ficticios. Las altas de los ejemplares están fechadas el 01/10/2026.

Los pasos concretos, reglas y resultados esperados están en la [guía de exposición](guia-exposicion.md). Las portadas se almacenan en el proyecto para que el catálogo funcione durante la exposición sin depender de un sitio externo.
